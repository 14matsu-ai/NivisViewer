# NivisViewer 1.0.21

- SVGとAIのサムネイル・Viewer表示に対応しました。フォルダ内やZIP内の画像として表示できます。
- SVGは静止画として表示し、拡大時は必要なサイズで描き直します。透過背景に対応しています。
- AIはPDF互換で保存されたファイルに対応し、保存されたPDFの先頭ページを表示します。非PDF互換AIや全アートボードの表示には対応していません。
- 「設定 → 書庫 → AI・SVG画像」に形式ごとの読み込みON/OFF、ツールチップと「？」ヘルプを追加しました。初期設定はONで、変更は再起動後に反映されます。

SVGの外部ファイル参照やアニメーションは非対応です。一部の効果やフォントは作成ソフトと表示が異なる場合があります。
