# NivisViewer 1.0.19

- BrowserとViewerに「関連付けで開く」を追加し、初期ショートカットをCtrl+Tにしました。
- Windowsで関連付け済みのアプリを直接起動します。関連付けがない場合だけアプリ選択画面を表示します。
- Viewerのメニューを隠している場合もショートカットが動作します。
- 見開き表示ではマウス下の画像を対象にします。画像上にない場合は表示中の主ページを対象にします。
- 書庫内の画像は選んだ1枚を元の形式で一時コピーし、外部アプリへ渡します。コピーを編集しても元の書庫は変更されません。

既存のショートカット設定は保持されます。以前の設定で空欄にしていた場合は設定画面でCtrl+Tを割り当ててください。
GIMP自身のPython環境に関する警告への修正は含みません。
