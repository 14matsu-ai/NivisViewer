# NivisViewer 1.0.18

- KRA・ORAの保存済み合成画像、CLIPの保存済みプレビューの表示に対応しました。
- XCF読み込みを追加しました。処理に時間がかかるため既定OFFです。
  「設定 → 書庫 → GIMP」で有効化し、アプリを再起動してください。
- 対応するXCF画像は直接読み込み、未対応の構成はインストール済みGIMP 3で変換します。
  GIMP実行ファイルの手動指定に対応しました。
- XCFサムネイルの処理枠を分離し、ほかの画像のサムネイルを待たせにくくしました。
- XCF設定に説明のツールチップと「？」ボタンを追加しました。

CLIPは保存済みプレビューの表示であり、原寸レイヤーの再描画ではありません。
XCFのマスク・グループ・効果や一部の合成方式などはGIMP変換が必要です。
実制作XCF全般の高速化を保証するものではありません。

## 検証

リリース前の対象テスト224件が成功。設定、画像ソース、サムネイル、
XCF直接読み込みとキャンセル、翻訳、バージョン、配布構成・ライセンスを含みます。
4096×6500・8ページの大画像ZIPの順送り・逆方向・往復・高速入力はoffscreenで確認済み。
固定リリース環境はPython 3.11 / PyInstaller 6.20.0 / PySide6 6.11.1 / Pillow 12.1.1。
実アプリ・GIMPの起動は禁止されているため、配布EXEの実起動確認は行っていません。
