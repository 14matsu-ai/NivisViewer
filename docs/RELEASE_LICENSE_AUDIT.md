# Source and dependency license requirements

NivisViewer is AGPL-3.0-or-later. Preserve `LICENSE`, `PROJECT_LICENSE.md`,
`THIRD_PARTY_NOTICES.md`, and the upstream notices in `licenses/`.
The ZipPlaFork mappings are in `docs/ZIPPLAFORK_COMPARISON.md`.

A distributed binary must have a matching Corresponding Source delivery route,
including required build material. A license text alone does not supply source.
Identify the exact dependency versions and the Qt modules actually included.
Fulfil their applicable source, attribution, modification/replacement and
installation requirements. Dependency license notices are not relicensed as AGPL.

Official references:

- GNU AGPL: https://www.gnu.org/licenses/agpl-3.0.html
- Qt for Python: https://doc.qt.io/qtforpython-6/licenses.html
- Qt third-party notices: https://doc.qt.io/qt-6/licenses-used-in-qt.html
- Qt Virtual Keyboard: https://doc.qt.io/qt-6/qtvirtualkeyboard-index.html
- CPython: https://docs.python.org/3/license.html
- PyInstaller: https://pyinstaller.org/en/stable/license.html

Inspect the source and native inventory of the exact package. This document
records requirements; it does not certify a package's license compliance.
